# Project Specification: Multi-Language Translation Web App

## 1. Project Overview
사용자가 텍스트(단어 및 문장)를 입력하고 원하는 언어로 번역할 수 있는 웹 애플리케이션을 개발한다.
타겟 언어 선택 시 사용자가 쉽게 언어를 찾을 수 있도록 **검색 기능이 포함된 언어 선택 UI(Language Selector with Search)**를 제공한다.

---

## 2. Tech Stack Recommendations
- **Frontend**: React / Next.js (또는 HTML5 + Tailwind CSS + Vanilla JS)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React / FontAwesome
- **Translation API**: DeepL API, Google Translate API, 또는 LibreTranslate (무료 오픈소스)

---

## 3. Key Features & Functional Requirements

### 3.1. Language Selection & Search (핵심 기능)
- **언어 선택 드롭다운/모달**:
  - 지원되는 언어 목록을 드롭다운 또는 검색 모달 형태로 제공.
  - 상단에 **검색 입력창(Search Bar)**을 배치하여 언어 이름(예: "한국어", "Japanese", "Spanish") 검색 시 실시간 필터링.
  - 최근 사용한 언어 또는 주요 언어(영어, 한국어, 일본어, 중국어 등) 상단 고정.
- **감지 기능**:
  - 원문 언어는 '자동 감지(Auto Detect)' 옵션 기본 제공.

### 3.2. Text Input & Output Area
- **입력 창 (Source Text)**:
  - 단어 및 긴 문장을 입력할 수 있는 Multi-line Textarea.
  - 입력 내용 전체 삭제 버튼(Clear Icon).
  - 글자 수 카운터 표시.
- **출력 창 (Translated Text)**:
  - 번역 결과 표시 영역 (Read-only).
  - 결과 복사(Copy to Clipboard) 버튼 및 복사 완료 Toast 알림.

### 3.3. Translation Logic
- 입력 후 번역 버튼 클릭 시 또는 입력 멈춤 감지(Debounce, 약 500ms) 시 API 호출.
- 로딩 상태 표시 (Skeleton UI 또는 Spinner).
- API 오류 발생 시 예외 처리 메시지 노출.

---

## 4. UI/UX Design Guidelines
- **레이아웃**: 
  - 데스크톱: 좌측(입력) - 우측(결과) 2열 구조.
  - 모바일: 상단(입력) - 하단(결과) 스택 구조.
- **디자인 톤앤매너**:
  - 깔끔하고 모던한 미니멀 디자인.
  - 직관적인 아이콘 사용 (검색, 복사, 지우기, 언어 교체).

---

## 5. Implementation Steps for Agent

1. **프로젝트 기본 설정**
   - 프로젝트 초기화 및 Tailwind CSS, 아이콘 라이브러리 설정.
2. **UI 컴포넌트 마크업**
   - 헤더, 텍스트 입력/출력 영역 카드 레이아웃 작성.
3. **검색 기능이 포함된 언어 선택 컴포넌트 개발**
   - 언어 리스트 데이터 정의 (코드 및 언어명).
   - 검색어 입력에 따라 필터링되는 Select/Combobox UI 구현.
4. **번역 API 연동 및 상태 관리**
   - API Key 환경변수(`.env`) 처리.
   - 입력값, 선택된 언어, 번역 결과를 관리하는 State 구축.
5. **부가 기능 추가 및 다듬기**
   - 클립보드 복사, 입력 지우기, Debounce 처리, Responsive UI 점검.

---

## 6. Coding Rules & Constraints
- 코드 모듈화: UI 컴포넌트, API 연동 로직, 언어 데이터 목록을 분리하여 작성할 것.
- API Key는 절대로 코드에 직접 하드코딩하지 말고 `.env` 파일로 관리할 것.
- 타겟 언어 검색 기능은 대소문자 및 띄어쓰기를 구분하지 않고 검색되도록 처리할 것.
